# Portafolio — Josué Martínez

Portafolio personal con animaciones 3D, construido con **Next.js**, **React** y
**TypeScript**.

Basado en la plantilla de código abierto
[3d-portfolio](https://github.com/Naresh-Khatri/3d-portfolio) de Naresh Khatri.

## Desarrollo

```bash
npm install --legacy-peer-deps
npm run dev
```

## Build

```bash
npm run build
```

El sitio estático se genera en `out/` y se despliega en **GitHub Pages** mediante
GitHub Actions (`.github/workflows/deploy.yml`).
