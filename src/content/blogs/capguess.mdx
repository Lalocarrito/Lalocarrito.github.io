# CapGuess — Juego educativo de geografía

CapGuess es la interfaz de un **juego educativo** pensado para niños de 10 a 12 años que quieren aprender el nombre de distintas **ciudades, estados, capitales y países**. Fue diseñado en **Figma** y permite interactuar con el prototipo.

## ¿Qué se pedía?

Diseñar la interfaz de un juego educativo: clara para niños, con navegación sencilla y una identidad visual atractiva.

## ¿Cómo se diseñó la solución?

Apliqué principios de **UI/UX**: jerarquía visual, colores vivos, tipografía legible y una distribución de botones pensada para que un niño no se pierda. Definí las pantallas principales y el flujo de navegación.

## ¿Cómo se implementó?

Construí todo en **Figma**, con componentes reutilizables, y dejé el prototipo **interactivo** para poder recorrer el flujo como si fuera la app real.

## Resultado

Fue una de las interfaces más completas que hice en la materia de ISI, porque integró todo lo aprendido: distribución de elementos, color, acciones y navegación.

## Lo que me llevé

Figma es una herramienta clave para el Frontend: permite visualizar ideas y hacer borradores antes de programar. Esta experiencia me dio una base sólida de **diseño de interfaces**.
